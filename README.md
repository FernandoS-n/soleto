# Soleto

Sitio oficial de Soleto: soluciones de energía solar en Torreón y La Laguna.

## Publicar en Cloudflare Pages

1. En Cloudflare abre **Workers & Pages → Create → Pages → Connect to Git**.
2. Selecciona este repositorio.
3. Deja vacío el comando de compilación.
4. Usa `dist` como directorio de salida.
5. Publica y después agrega tu dominio desde **Custom domains**.

El sitio es estático y no necesita variables de entorno.
